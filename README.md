# NBA-data-analysis

Data based on the NBA 25-26 SZN

Features:
1.  Rank Column: Finds the top 5 and bottom 5 players in chosen column in CSV (except for PLAYER_ID, PLAYER, TEAM_ID, and TEAM)
2.  Longevity: Finds the top 5 and bottom 5 players in total minutes played over total games played
3.  Free Throw Merchant: Finds the top 5 (free throw merchant) and bottom 5 (ethical hooper) players
